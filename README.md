# PixelCraft — Agency Website

A modern and responsive frontend agency website designed to showcase web design and frontend development services.

## 🌐 Live Demo

**Live Website:** https://pixelcraft-agency-bd.netlify.app/

## 📌 About the Project

PixelCraft is a frontend agency website created as a portfolio project. The website focuses on a clean, modern interface, responsive layouts, and a professional presentation of web development services and projects.

## ✨ Features

* Responsive design for mobile, tablet, and desktop
* Modern and clean user interface
* Professional agency-style layout
* Services section
* Projects portfolio section
* Project details pages
* About page
* Contact page
* Responsive navigation
* Call-to-action sections
* Mobile-friendly layouts

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Font Awesome
* Google Fonts

## 📄 Website Pages

* Home
* About
* Services
* Projects
* Project Details
* Contact
